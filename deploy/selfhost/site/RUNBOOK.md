# Сайт oneflow.art с сервера в Казахстане вместо Vercel

Сайт (лендинг RU/EN, приложение `/app`, админка `/admin`) раздаёт Caddy на том же сервере,
что и `api.oneflow.art`. Поведение то же, что на Vercel: адреса без `.html`, те же защитные
заголовки, страница 404, кэш.

## Первый раз

С компьютера (по одной команде):

    scp oneflow-site.tar.gz oneflow-art-site-v18.1.zip <пользователь>@91.103.106.229:~

На сервере:

    tar xzf oneflow-site.tar.gz
    sudo bash ~/oneflow-site/install-site.sh ~/oneflow-art-site-v18.1.zip

Посетители пока ничего не замечают: сайт отвечает только внутри сервера (127.0.0.1:8088),
и на нём идут проверки.

## Переключение (лучше ночью: у части посетителей сайт недоступен 1–5 минут)

1. На сервере: `sudo oneflow-site go-live`. Команда проверит сайт и будет ждать смены DNS.
2. В Vercel → Domains → oneflow.art → DNS Records:
   - удалить записи для `@` и `www`, которые ведут на Vercel (если они есть в списке);
   - добавить `A  @  91.103.106.229` и `A  www  91.103.106.229` (TTL 60).
   Если через 2 минуты на экране сервера всё ещё нет ✓, то в проекте Vercel → Settings →
   Domains убрать `oneflow.art` и `www.oneflow.art` (DNS-записи домена при этом остаются).
3. Команда сама дождётся DNS и выпустит сертификат, затем проверит сайт через HTTPS и напишет «Готово».
4. Проверить в браузере: главная, /ru, вход по почте и через Google, регистрация, админка.

## Обновления

    sudo oneflow-site deploy ~/oneflow-art-site-vNN.zip   # новая версия (при ошибке сам вернёт прежнюю)
    sudo oneflow-site rollback                            # вернуть предыдущую версию
    sudo oneflow-site status                              # версии, DNS, сертификат
    sudo oneflow-site check                               # все проверки ещё раз

Если когда-нибудь снова запускать `oneflow-install.sh`, он перепишет `/etc/caddy/Caddyfile`;
после него выполнить `sudo oneflow-site setup`: команда вернёт сайт в настройки Caddy.

## Откат на Vercel (если что-то пошло не так после переключения)

1. В Vercel DNS удалить записи `A @ 91.103.106.229` и `A www 91.103.106.229`.
2. В проекте Vercel → Settings → Domains снова добавить `oneflow.art` и `www.oneflow.art`.
3. Через 1–5 минут сайт снова откроется с Vercel (там последняя загруженная версия).

Проект в Vercel не удалять 2 недели — это запасной путь. Потом его можно удалить; DNS-зона
домена в Vercel при этом остаётся (в ней нет персональных данных).
