Условия использования ONEFLOW

Последнее обновление: заполните дату при публикации.

1. Услуга

ONEFLOW — desktop-приложение для генерации и адаптации изображений/видео с помощью сторонних нейросетевых моделей. Доступ к приложению предоставляется по подписке.

2. Учётная запись

Доступ выдаётся администратором приложения на основании email и пароля. Пользователь обязуется не передавать свои учётные данные третьим лицам.

3. Оплата и подписка

Подписка оплачивается через платёжного партнёра LemonSqueezy.com (LemonSqueezy обрабатывает платежи как продавец по договору). Стоимость и период оплаты указаны на странице оформления подписки.

4. Допустимое использование

Запрещается использовать сервис для создания незаконного контента, нарушения прав третьих лиц, а также для действий, нарушающих условия использования сторонних нейросетевых сервисов, к которым обращается приложение.

Сервис предоставляется «как есть». Администратор не несёт ответственности за контент, сгенерированный пользователем с помощью приложения.
